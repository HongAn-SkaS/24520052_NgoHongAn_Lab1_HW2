# Project Rules – Drum Kit Engine
- Vanilla HTML5, modern CSS, ES6+ JS only.
- No jQuery, Bootstrap, Tailwind, external CDN.
- Contract-First: HTML data-sound committed BEFORE JS.
- const by default, let only if reassigned.
- Never innerHTML with user input.
- Atomic commits. No monolithic. No one-shot AI.
- Audio engine must be decoupled from UI triggers.
